# Roadmap

Durations are planning guesses. Each phase ends at a gate. Do not start the next phase before the gate passes. Scope follows section 15.8 of the design guide.

## Phase 0: Shell and design system (about 4 weeks)
- [ ] Monorepo, tokens, shell, function registry, command palette
- [ ] Five archetype templates, table engine v1, FX basis control, Storybook
- [ ] Onboarding flow, personal home, mobile layout, Data saver mode (design and mock)
- [ ] Quote popover and security tab strip
- Gate 0: clickable product on mock data reviewed by five target users

## Phase 1: First real data (about 8 to 10 weeks)
- [ ] Auth, symbol master, search for the first two markets
- [ ] Retail core loop: watchlist, chart (basic indicators), quote header, simple financials, snapshot, price alerts on delayed data
- [ ] Installable mobile web app, Trader / Investor / Advisor templates
- Gate 1: licence covers what is shown, latency within budget, no known wrong numbers on top 50 names

## Phase 2: Live and local (about 8 weeks)
- [ ] Remaining launch exchanges, movers, regulatory wire, AFX, ADTV, FLOW, LIM
- [ ] Chart drawings, indicators, multiple timeframes
- [ ] Portfolio v1 and advisor basics
- Gate 2: exchanges live, gateway load tested, data review queue staffed

## Phase 3: Research and advisors (about 8 weeks)
- [ ] Estimates, ownership, screens
- [ ] Client portfolios, model portfolios, report builder, Excel and PDF export, billing
- Gate 3: an advisor can run a client review end to end; an analyst can screen, read and chart in one product

## Phase 4: Pro depth
- [ ] Fixed income and macro, command grammar, public API, more markets, detachable windows

## Phase 5: Institutions
- [ ] Teams, SSO, audit exports, API service levels, data distribution, order routing through partners
